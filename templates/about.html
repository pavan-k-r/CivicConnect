About CivicConnect

CivicConnect is a community problem reporting system that allows citizens to report public problems and track their complaints easily.

Our Purpose

CivicConnect helps citizens report common public issues such as potholes, garbage, damaged roads, streetlights, water problems and traffic problems.

How It Works

1. Report: Select the problem type, describe the issue and enter its location.

2. Track: Use the unique Tracking ID generated after submission to check your complaint.

3. Improve: The system helps organize reported problems and supports better communication about community issues.

Technology Used

Frontend: HTML, CSS

Backend: Python Flask

Database: SQLite
